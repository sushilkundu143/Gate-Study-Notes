## How These Notes Are Organised

Every subject folder has:

1. A `README.md` with the official syllabus, study order and a checklist.
2. One file per syllabus topic with concepts, worked examples, shortcuts and common traps.
3. A solved PYQ (previous year questions) bank grouped by topic.
4. A one-page revision / formula sheet for the last week before the exam.
